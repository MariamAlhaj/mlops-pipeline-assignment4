# mlops-pipeline-assignment4

This repository contains a CI/CD pipeline for ML model validation.

## Project Structure
- `.github/workflows/` - Contains GitHub Actions workflows
- `requirements.txt` - Python dependencies
- `README.md` - Project documentation

## Pipeline Features
- Automated testing on push to non-main branches
- Python environment setup
- Code linting with flake8
- PyTorch environment validation
- Artifact upload of documentation 
## CI/CD Pipeline Info 
This repository contains a GitHub Actions workflow for ML model validation.
